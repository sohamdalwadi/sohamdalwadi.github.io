### 🤖 QBIT

An open-source desktop robotic companion and IoT avatar built around the **ESP32-C3** RISC-V microcontroller.

#### Key Highlights
- **Embedded C / C++**: Real-time firmware running on ESP32-C3 with low latency sensor and motor controls.
- **Companion Logic**: Desktop automation, interactive display feedback, and IoT sensor telemetry.
